# DarkRoastData IAM Cybersecurity Portfolio

## About This Portfolio

This is my student Identity and Access Management (IAM) portfolio.

I created these projects to learn how organizations manage user
identities, access, authentication, and application permissions.

The company used in these projects, **DarkRoastData**, is fictional.

My main areas of interest are Identity and Access Management,
identity lifecycle management, Single Sign-On (SSO), access control,
and authentication.

---

## IAM Areas

- Identity Lifecycle Management
- Joiner-Mover-Leaver (JML)
- RapidIdentity concepts
- Google Workspace
- Single Sign-On (SSO)
- Role-Based Access Control (RBAC)
- Multi-Factor Authentication (MFA)
- Least Privilege
- Access Reviews
- User Provisioning
- User Deprovisioning

---

## Projects

### 01. Identity Lifecycle Management – JML

A simulated project showing how user access can be managed when
employees join, change roles, or leave an organization.

**Topics:**
- Joiner
- Mover
- Leaver
- User provisioning
- User deprovisioning
- Access reviews
- Least privilege

### 02. RapidIdentity – IAM Concepts

A learning project focused on how an IAM platform can be used to
manage identities, groups, roles, application access, and SSO.

### 03. Google Workspace – SSO

A learning project showing how Google Workspace can fit into an
organization's SSO and IAM environment.

### 04. Role-Based Access Control – RBAC

A project demonstrating how employee roles can be used to organize
and control access to applications and resources.

### 05. Multi-Factor Authentication – MFA

A project explaining how MFA can be used as part of an IAM
authentication process.
